# Streamlit UI — Diabetes Mellitus Classification

Baca `RUN_STREAMLIT.md` untuk setup dan cara menjalankan aplikasi. UI memuat dashboard, formulir simulasi klasifikasi 33 fitur, hasil prediksi, informasi arsitektur, dan batasan penggunaan.

Artefak model yang disertakan: `models/stacking_diabetes.joblib`.

**Peringatan:** prototipe penelitian berbasis dataset Kaggle, bukan alat diagnosis atau keputusan medis. Skor holdout yang sangat tinggi perlu dibaca bersama temuan pola target yang sangat terstruktur di `VALIDATION_NOTES.md`.
